# Quotes Web Scraper

A simple Python web scraper that extracts quotes, authors, and tags from **https://quotes.toscrape.com** using the `requests` and `BeautifulSoup` libraries.

## Requirements

- Python 3
- requests
- beautifulsoup4
- pipenv

## Running the Script

```bash
py -m pipenv install
py -m pipenv run python main.py
````

## Output

The script prints each quote, its author, and associated tags to the terminal.
